WebDocs 📝

WebDocs is an online collaborative document editor where users can create, edit, and manage documents in real-time. Perfect for teams, classrooms, or remote collaboration, it allows multiple users to work on the same document simultaneously.

Features

Real-time Collaboration: All edits are instantly synced for all users viewing the document.

Multi-User Editing: Supports multiple users editing the same document simultaneously.

Document Management: Create, save, and organize documents effortlessly.

Responsive Interface: Built with React and Tailwind CSS for a clean, modern UI.

Instant Updates: Powered by Socket.IO for real-time communication.

Secure Storage: Documents are safely stored in MongoDB.

Tech Stack

Frontend: React, Tailwind CSS

Backend: Node.js, Express

Database: MongoDB

Real-time Updates: Socket.IO

Development Tools: Nodemon, VSCode

Installation
Frontend
# Clone the repository
git clone https://github.com/yourusername/webdocs.git
cd webdocs/frontend

# Install dependencies
npm install

# Start the development server
npm start

Backend
cd ../backend



# Start the server with Nodemon
nodemon server.js



Running the App

Start the backend server first: npm run dev

Start the frontend React app: npm start

Open http://localhost:3000 in your browser.

Create or open a document and invite collaborators. Changes are reflected in real-time.
